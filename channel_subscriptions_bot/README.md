# Channel subscriptions bot

Автономный Telegram-бот для отслеживания подписок и отписок в канале.

## Запуск

```bash
cd /Users/amonulloh/Documents/klch_project/kulcha/channel_subscriptions_bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## Как пользоваться

1. Напиши боту `/start` в личные сообщения. Он сохранит твой Telegram ID как владельца.
2. Добавь бота в свой канал администратором.
3. Когда бот получит права администратора, он привяжет канал к владельцу канала, если владелец уже нажал `/start`. Если владельца нельзя определить, бот привяжет канал к тому, кто добавил его в канал и уже нажал `/start`.
4. После этого бот будет писать владельцу в личку:
   - кто подписался;
   - кто отписался;
   - из какого канала;
   - точное время события.

## Команды

- `/start` - запомнить текущего пользователя как владельца.
- `/channels` - показать каналы, которые привязаны к тебе.
- `/help` - краткая помощь.

## Важно

- Бот видит только события, которые произошли после добавления его администратором.
- Прошлую историю подписок Telegram не отдает.
- Чтобы получать события, процесс `python bot.py` должен быть запущен.
- Если бот не пишет о событиях, удали его из администраторов канала, нажми `/start` в личке и добавь заново администратором.
